### Buổi 2 — Thực hành: video đầu tiên end-to-end

Làm **1 video ngắn 30–60 giây** từ đầu đến cuối, đúng 3 bước của tool:

1. **Nhập ý tưởng**: Tạo dự án → mô tả ngắn câu chuyện (1–2 câu tiếng Việt).
2. **AI viết kịch bản**: Bấm để AI tạo *chủ đề → lời đọc → phân cảnh*. Đọc lại, sửa chỗ chưa ưng (giọng văn, độ dài).
3. **Dựng và xuất video**: Kiểm tra hình ảnh/giọng đọc từng cảnh → Xuất video → mở file kiểm tra.

Sau buổi này bạn đã biết "đường đi" của tool. Mọi tính năng khác chỉ là mở rộng.

### Buổi 3 — Tạo ảnh Google Flow hàng loạt (extension v1.2)

1. Tải ZIP extension (đường dẫn tải nằm trong mục *Cách dùng → Extension tạo ảnh hàng loạt*).
2. Giải nén → mở `chrome://extensions` → bật **Chế độ dành cho nhà phát triển** → **Tải tiện ích đã giải nén** → chọn thư mục `google-flow-extension` (chứa `manifest.json`).
3. Mở dự án trên **Google Flow** → bấm biểu tượng extension → bảng điều khiển mở bên cạnh.
4. Bấm **Tải mẫu JSON** để xem định dạng; mỗi scene cần `prompt`, có thể thêm `id`, `character`, và **tên ảnh** để tool tự đổi tên.
5. Dán danh sách scene (hoặc chọn file `.json`) → bấm **Tạo ảnh** → theo dõi tiến trình → ảnh về đúng tên, không phải đổi tay.

### Buổi 4 — Tạo kịch bản bằng prompt / plugin GPT (cách cũ, v1.0–1.4, vẫn hữu ích)

- **Cách 3.1 — Dùng prompt**: tải file prompt của nhóm → dán vào công cụ AI bạn dùng (ChatGPT/Gemini...) → gửi concept → nhận kịch bản + prompt phân cảnh.
- **Cách 3.2 — Dùng plugin GPT "YT Create"**: cài plugin vào môi trường GPT hỗ trợ plugin → gửi concept → nhận kịch bản + prompt phân cảnh.
- Quy trình đầy đủ: gửi concept → có lời đọc → **gửi file SRT** → AI trả về **danh sách phân cảnh dạng JSON** (mỗi cảnh có `prompt` tạo ảnh + `subtitle_ids` khớp phụ đề) → đưa JSON này vào tool/extension.

### Buổi 5 — Gỡ watermark (kỹ năng phụ, dùng thường xuyên)

- Ảnh (Google Flow) và video (Omini AI, Veo 3) — kéo thả **hàng loạt** nhiều file cùng lúc.
- Lưu ý: chỉ dùng cho nội dung bạn có quyền xử lý.
